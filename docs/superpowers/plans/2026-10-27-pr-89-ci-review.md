# PR #89 CI Review Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve Massini's two PR #89 review comments without weakening pre-merge verification or changing application-owned code.

**Architecture:** Keep the single `CI` workflow and its stable `Backend`, `Container`, and `CI Gate` checks. Limit push verification to `main`, retain pull-request verification, cancel only superseded runs for the same pull request, give every non-PR run a unique concurrency group, and restore `upload-artifact`'s default compression for the main-branch Docker image TAR.

**Tech Stack:** GitHub Actions, PowerShell, actionlint, Docker/Compose, Java 25, Maven Wrapper.

**Spec:** PR #89 review comments and `docs/superpowers/specs/2026-10-21-issue-2-ci-design.md`

## Global Constraints

- Preserve Java 25, Maven Wrapper verification, Docker build verification, the `CI Gate`, pinned actions, `contents: read`, and seven-day artifact retention.
- Pull requests targeting `main` and pushes to `main` must run CI; ordinary feature-branch pushes must not.
- Only superseded pull-request runs may be canceled; `main` runs and different pull requests must not cancel each other.
- Do not modify backend, database, frontend, Dependabot, deployment, or branch protection.
- Do not merge, force-push, discard local work, or rewrite PR history.

## Review Focus

- A feature-branch commit with an open PR must create one verification run, not both `push` and `pull_request` runs.
- `CI Gate` must retain its display name and dependency semantics so required-check configuration is not stranded.
- Main-branch image save/upload steps must remain main-push-only after trigger changes.
- Concurrency groups must isolate pull requests and must not cancel in-progress `main` runs.
- Removing `compression-level: 0` must leave artifact name, path, missing-file handling, retention, and action pin unchanged.
